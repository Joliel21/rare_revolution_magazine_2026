# RARE Revolution Magazine content repository

This repository contains publication/client content only for the reusable white-label magazine reader.

Allowed here: organization branding data, issue metadata, editorial/content JSON, sponsor data, and publication assets required at runtime.

Not allowed here: React/TypeScript reader source, Vite configuration, npm/package files, build scripts, generic white-label templates, or compiled reader bundles.

The reusable reader/build is maintained separately in OneDrive.
